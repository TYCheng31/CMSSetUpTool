# CMS 自動化設定工具

傳統的 CMS (Contest Management System，競賽管理系統) 需要手動設定每一道題目。此工具利用基於 Python 的網頁爬蟲，將設定過程完全自動化。
CMS: http://cms-dev.github.io/
* **相容性：** 適用於非虛擬環境的 CMS 。
* **測試環境：** Ubuntu 22.04

## 安裝

一鍵安裝

```bash
curl -sSL https://raw.githubusercontent.com/TYCheng31/CMSSetUpTool/master/install.sh | bash
```
